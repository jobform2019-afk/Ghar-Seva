# GharSeva — Flutter MVP

A professional job marketplace prototype for:
- Cook jobs
- Housekeeping jobs
- Job seekers
- Employers / households

## Current UI flows
1. Role selection
2. Job seeker home
3. Job search & filters
4. Job details
5. Job seeker profile
6. Employer dashboard
7. Post a job
8. Applicants list
9. Messages placeholder

## Run
Install Flutter 3.x, then:

```bash
flutter pub get
flutter run
```

This is an MVP UI prototype. Backend, authentication, maps, payments, real-time chat,
ID verification, notifications and production database are the next phase.
